# frontend/AGENTS.md

React 18 + Vite 5 SPA: public site, admin, timekeeper. Read the root [AGENTS.md](../AGENTS.md) first.
The timekeeper's offline layer has its own rules: [src/offline/AGENTS.md](src/offline/AGENTS.md).

## Layout

- `src/Router.jsx` — all routes (public Czech URLs like `/zavody`, `/vysledky`; `/admin/*`; `/timekeeper/*`; `/__ms` kit catalogue, dev only).
- `src/config/api.js` — three clients: `API` (public), `AdminAPI` (JWT), `TimekeeperAPI` (JWT, offline-first).
  `config/session.js` keeps the one shared token (`auth_token`).
- `src/components/ms/` — the **Modrá stopa kit** (barrel `index.js`); `components/site/` — public site frame;
  `components/pages/<Page>/`, `components/admin/<Area>/`, `components/timekeeper/<Area>/` — screens.
- `src/utils/`, `src/hooks/` — pure logic (`utils/races.js`, `utils/results.js`, `hooks/useCurrentSeason.js`).
- `src/pdf/` — pdfmake documents (start lists, results). `src/offline/` — IndexedDB layer.
- `scripts/check-styles.mjs`, `check-imports.mjs`, `check-orphans.mjs` — project rules as executable checks.

## Rules

- **Logic out of components.** Screens render; decisions live in `utils/` or hooks with unit tests.
- **Every component is a folder** `Name/Name.jsx` + `Name.module.css` + `Name.test.jsx`.
- **Season**: "current season" comes from `hooks/useCurrentSeason.js`; `utils/season.seasonIdForDate` only converts dates.
- **Tests**: Vitest + Testing Library, query by role and visible Czech text, not by CSS class.
  Run the tests related to what you changed: `npx vitest related --run <files>`.

## Design system: Modrá stopa (binding)

Tokens: `src/styles/ms/tokens.css` (every value), kit: `src/components/ms/` (catalogue `/__ms` in dev).
The rules below are binding and take precedence over the generic
`frontend-design` skill: use that skill for composition and copy within the system, never for new fonts,
colours or a new visual direction.

- **The kit is the only vocabulary.** New UI is composed from `components/ms/`: actions (`Button`, `ButtonLink`,
  `IconButton` with mandatory `label`, `CloseButton`, `Tooltip`), `Icon` (stroke SVG registry `Icon/icons.js`,
  generated by `scripts/icons/build-icons.mjs`; new icons: viewBox 24, round caps, stroke ~2), data (`Badge`,
  `Paska`, `BibDate`, `DataRow`, `Rank`, `PageHeader`, `Panel`, `Table` + `TableScroll`, `Pagination`), forms
  (`Field` + `Input`/`Select`/`Textarea`, `Combobox`, `RadioTiles`, `Checkbox`, `Switch`, `SegmentedControl`),
  states (`Spinner`, `LoadingState`, `EmptyState`, `Alert`, `Modal` + `useDialog`, `LivePill`, `LiveBand`,
  `VisuallyHidden`), layout (`Container`, `Stack`, `Cluster`, `Grid`, `Split` — they only know `gap`; `Screen` is
  the root of a screen). Confirmations use `ConfirmDialog` via `hooks/useConfirm.jsx` (`danger: true` for
  destructive choices). Menu and footer links come only from `components/ms/navItems.js`.
- **No explanatory text in screens** — no description under a heading, notes under a toolbar or hints in empty
  states. A necessary note is a 2–6 word `Tooltip` on the button it concerns.
- **Warm accent** (`--ms-sun`, `--ms-sun-ink`) only where the system defines it: ribbon (first 40 px), active
  header item, eyebrow, `Button variant="accent"` (max one per screen), `Badge tone="accent"`, `Rank` 1st
  place, `BibDate` labels, footer column headings. Never a section background or a status. Shadows only
  `--ms-shadow-raised` and `--ms-shadow-dialog`.
- **No logo or emblem.** Identity is the cup's name in type and colour; PDF headers show only the organising
  club's logo. Exception: favicon and app icons (`public/favicon*`, `icon-*`, `apple-touch-icon.png`).
- **Styles only in `*.module.css`** next to the component; colours, spacing and type only via `var(--ms-*)`
  from `src/styles/ms/tokens.css` (JS mirror for Chart.js and bib colours: `components/ms/tokens.js`). The only
  global CSS is `src/styles/ms/` (tokens, self-hosted fonts, zero-specificity reset, focus, reduced motion, `.ms-sr-only`).
- **Forbidden in kit and modules** (enforced by `npm run check:styles`, also part of `npm test`): Bootstrap
  classes, `bi-*`, `--bs-*`, legacy variables (`--text-*`, `--sunset-orange`, `--glass-bg`, `--tk-*`, `--adm-*`,
  `--jmlp-*`), `theme-backoffice`, emoji, imports from `components/ui|layouts`, hex colours, `!important`,
  `@media` other than 768/1024/1280 (`max-width: 767.98px` style; 1440 only for dense frame toolbars), `z-index`
  outside `var(--ms-z-*)`, global selectors, `style={{}}` with anything but custom properties, style
  dependencies (Tailwind, react-bootstrap, CDN fonts). The baseline `scripts/style-baseline.json` is empty and
  must stay empty.
- **Accessibility**: icon buttons have `aria-label`, state is never colour alone, touch targets ≥ 44 px, dialog
  focus on the safe option (`data-autofocus`) or Cancel (`data-cancel`).

## Timekeeper screens

Built for laptops and tablets from **600 px** (iPad mini portrait 744, split view, narrow windows; iPad
768–1366; laptops 1280–1920), not phones. The frame (`TopBar` + `TabBar`) is sticky; below 1280 px tabs show
icon + short label (`short` in `navItems.js`). Between 600 and 767 px everything adapts without horizontal page
scroll: status badges drop icons, tabs scroll inside their bar (edge shadow, active tab scrolled into view),
wide tables scroll in their own box. Below 600 px the frame keeps 600 px and the page scrolls. No phone
layouts. Sticky elements offset by `--ms-sticky-top`. Check: no timekeeper route overflows at 600–1366 px.

Fonts are self-hosted (`src/styles/ms/fonts.css`, preloaded via `vite/fontPreload.js` for service-worker
precaching). **Bump `CACHE_NAME` in `public/sw.js`** whenever the app shell, icons or fonts change.
